# Reproducibility materials

Version **2.0.0** of the reproducibility package supporting the article **“Student Engagement in Technology-Mediated Hybrid Higher Education: An Exploratory Institutional Case Study”**.

The repository contains the anonymised questionnaire dataset, the complete Python workflow, verified numerical output and the analytical figures generated by the verified execution. The figures and lexical-results CSV can be regenerated by running the workflow. The article manuscript and conference-administration files are not included in this repository.

## Analytical sample

The cleaned workbook contains 70 records. One record lacks informed consent and valid weekly study hours and is excluded. The final analytical sample therefore contains 69 participants, matching the article.

All quantitative variables used in the analyses are complete for the 69 analytical participants. No imputation or partial composite scoring is required.

## Running the analysis

Use Python 3.9 or later. The results were verified with Python 3.10.12.

```bash
pip install -r requirements.txt
python reproducibility_analysis.py
```

The script first looks for `Questionario_Limpo.xlsx` in the same directory. It also accepts the English filename `Questionnaire_Clean.xlsx` for compatibility with local copies. If neither local file is present, it attempts to retrieve the current public Zenodo record.

## Analyses reproduced

The workflow reproduces:

1. KR-20 reliability estimates for the three behavioural aggregates;
2. descriptive statistics and graphical summaries;
3. Spearman correlations with bootstrap confidence intervals;
4. item-level analyses with Holm-adjusted p-values;
5. gender comparisons using Mann–Whitney tests and Cliff’s delta;
6. robust regression models, including programme-composition sensitivity analyses;
7. exploratory clustering with validation and a robustness analysis excluding weekly study hours;
8. scripted lexical analysis of open-ended responses by a priori questionnaire category.

## Reproducibility

All stochastic procedures use `RANDOM_STATE = 42`. Confidence intervals for the principal Spearman correlations and Cliff’s delta estimates use 10,000 bootstrap resamples. Cluster stability uses 200 bootstrap resamples.

## Language and source values

Documentation, output and plot labels use British English. Portuguese strings are retained only where required to recognise the original questionnaire responses or to report participants’ original lexical terms.
